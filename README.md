# Agents Under the Hood

A hands-on look at how LLM agents work internally. Instead of relying on a pre-built agent framework, this project hand-rolls the core **tool-calling agent loop** (the ReAct pattern) twice: once with LangChain, and once with the raw provider SDKs. Both versions run on a local Ollama model or on OpenAI GPT-5.

## Project structure

| File | Description |
| --- | --- |
| `1_agent_loop_langchain_tool_calling.py` | A shopping-assistant agent that uses LangChain's `@tool`, `init_chat_model` and `.bind_tools()` with a manual loop to call `get_product_price` and `apply_discount` until it reaches a final answer. |
| `2_agent_loop_raw_function_calling.py` | The same agent without LangChain: calls the raw Ollama / OpenAI SDKs, with hand-written JSON tool schemas and manual LangSmith tracing. |
| `main.py` | Minimal entry point / hello-world. |
| `.env.example` | Template for the environment variables (provider, API keys, LangSmith). |
| `pyproject.toml` / `uv.lock` | Project dependencies, managed with [uv](https://docs.astral.sh/uv/). |

## How the agent loop works

1. Send the conversation (system prompt + user question) to the LLM, along with the tool schemas.
2. If the LLM responds with a tool call, run that Python function.
3. Append the tool call and its result to the conversation.
4. Repeat until the LLM answers in plain text (or `MAX_ITERATIONS` is reached).

## LangChain vs. raw function calling

Comparing the two scripts shows what LangChain does for you:

| | `1_` LangChain | `2_` Raw SDKs |
| --- | --- | --- |
| Model client | `init_chat_model("ollama:...")` / `("openai:...")` | `ollama.chat()` / `OpenAI().chat.completions.create()` |
| Tool schemas | Generated by `@tool` from type hints and docstrings | Written by hand as JSON Schema |
| Messages | `SystemMessage`, `HumanMessage`, `ToolMessage` | Plain dicts with a `role` key |
| Provider differences | Hidden behind one interface | Handled manually (response shape, JSON-string arguments, `tool_call_id`) |
| LangSmith tracing | LLM and tool calls traced automatically | Each LLM and tool call wrapped in `@traceable` |

## Prerequisites

- Python 3.12+
- [uv](https://docs.astral.sh/uv/getting-started/installation/)
- [Ollama](https://ollama.com/) running locally, with a model that supports tool calling:

  ```bash
  ollama pull qwen3:1.7b
  ```

- An OpenAI API key, if you want to use GPT-5

## Setup

Install dependencies:

```bash
uv sync
```

Copy the example env file and fill in your keys:

```bash
cp .env.example .env
```

`OPENAI_API_KEY` is only needed for the OpenAI provider, and the `LANGSMITH_*` keys are optional (for tracing). `.env` is git-ignored, so never put real keys in `.env.example`.

## Running

```bash
uv run 1_agent_loop_langchain_tool_calling.py
uv run 2_agent_loop_raw_function_calling.py
```

Example output:

```text
Hello LangChain Agent (.bind_tools)!

Model: ollama:qwen3:1.7b
Question: What is the price of a laptop after applying a silver discount?
============================================================

--- Iteration 1 ---
  [Tool Selected] get_product_price with args: {'product': 'laptop'}
    >> Executing get_product_price(product='laptop')
  [Tool Result] 1299.99

--- Iteration 2 ---
  [Tool Selected] apply_discount with args: {'price': 1299.99, 'discount_tier': 'silver'}
    >> Executing apply_discount(price=1299.99, discount_tier='silver')
  [Tool Result] 1143.99

--- Iteration 3 ---

Final Answer: The original price of the laptop was $1299.99. After applying the silver discount, the final price is **$1143.99**.
```

## Switching models

Both scripts take a `--provider` flag (defaults to local Ollama):

```bash
uv run 1_agent_loop_langchain_tool_calling.py --provider ollama   # qwen3:1.7b
uv run 1_agent_loop_langchain_tool_calling.py --provider openai   # gpt-5

uv run 2_agent_loop_raw_function_calling.py --provider ollama
uv run 2_agent_loop_raw_function_calling.py --provider openai
```

You can also set the default in `.env` with `LLM_PROVIDER=openai`. To change the model names, edit the `MODELS` dict in each script.

## LangSmith tracing

With `LANGSMITH_API_KEY` and `LANGSMITH_TRACING=true` in `.env`, every run is sent to the LangSmith project named by `LANGSMITH_PROJECT` (default in the template: `agents-under-the-hood`). Look for these root runs:

- **LangChain Agent Loop**: from `1_agent_loop_langchain_tool_calling.py`
- **Raw Agent Loop**: from `2_agent_loop_raw_function_calling.py`

Each run contains its LLM calls and tool calls nested under it.
